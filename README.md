## ✨ Core Features

- _Secure Authentication:_ User signup, login, and protected routes using _Supabase_ authentication services.
- _Dynamic Cabin & Booking Management:_ Full CRUD (Create, Read, Update, Delete) functionality for managing the hotel's cabin inventory and processing guest bookings.
- _Real-Time Dashboard:_ A central hub providing vital, visualized _statistics on sales, check-ins, and occupancy rates_.
- _Settings Module:_ Administrators can dynamically update critical parameters, such as breakfast costs and other service extras. -_Bookings Module:_ Administrators can easily managa the bookings, check-in guests, check-out guests, add breakfast for guests and other services
- _User Experience:_ Includes a seamless _Dark Mode feature_ for comfortable late-night usage, demonstrating attention to modern UI/UX standards.
- _Code Quality:_ All components are atomic and _fully reusable_ across the application, promoting scalability and maintainability.

## ⚙ Getting Started

Follow these steps to set up the project locally.

### Prerequisites

You will need the following installed on your machine:

- Node.js (LTS version)
- npm or yarn

### Installation

1.  _Clone the repository:_
    bash
    git clone [https://github.com/olayinkasanusi/the-wild-oasis.git](https://github.com/olayinkasanusi/the-wild-oasis.git)
    cd the-wild-oasis

2.  _Install dependencies:_
    bash
    npm install

    # or

    yarn install

3.  _Setup Environment Variables:_
    Create a .env file in the root directory and add your Supabase connection details (these must be kept secret and should not be committed to Git).

    # Example .env structure

    REACT_APP_SUPABASE_URL=your_supabase_project_url
    REACT_APP_SUPABASE_KEY=your_supabase_anon_public_key

    Note: You will need to set up the corresponding tables and RLS policies in your Supabase dashboard.

4.  _Run the application:_
    bash
    npm run start

    # or

    yarn start

    The application will run on http://localhost:3000.
